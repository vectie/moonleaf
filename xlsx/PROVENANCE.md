# XLSX implementation provenance

MoonLeaf's XLSX code is an original MoonBit implementation based on the
published Office Open XML package structure and the ECMA-376 terminology for
workbooks, relationships, shared strings, worksheets, and cell types.

The public SheetJS Community Edition documentation was consulted only as a
behavioral reference for common interoperability cases. No SheetJS source code
was copied or translated. Any future source-level port must first record the
exact upstream version, file, license, and retained notices here.
